# くらし帖（統合テスト版）

「かいもの帖」と「持ち物台帳」を、既存データを変更せずに一つの画面で確認する第1段階の統合版です。

## 保存キー

- 統合版: `kurashi-cho-v1`
- 読み取り元: `kaimono-memo-v1`, `mochimon-v7`

統合版は読み取り元を直接変更せず、ユーザー確認後にコピーを作ります。

iPhoneの保存領域の違いなどで自動検出できない場合は、各アプリから書き出したJSONを個別に取り込めます。

## 第2段階

- 買うもの・在庫・持ち物を統合版から直接追加
- 在庫数量と持ち物の保管場所を編集
- 購入品を在庫または持ち物へ振り分け
- 持ち物として登録する購入品には保管場所を指定
- 元アプリから再取り込みする前に統合データを自動バックアップ
